# v0.dev 设计 Prompt — 内在结构养育网站

> 直接复制下方全部内容，粘贴到 https://v0.dev 的输入框中。

---

```
我需要设计一个名为"内在结构养育"的育儿方法论网站（nzyy.cc）。

【品牌定位】
- 品牌名：内在结构养育
- 核心理念：一套以"心神"为核心的育儿方法论
- 目标用户：一二线城市高学历家长，30-45岁
- 品牌调性：理性、克制、温和、有理论深度也有生活温度
- 不制造焦虑，不承诺功利结果

【色彩系统】
- 主色：#f59e0b（暖橙）
- 背景：#FFFBF5（米白）
- 文字：#78350f（深棕）
- 强调色：#fef3c7（浅暖黄）
- 风格：克制从容，留白充足，移动优先

【字体】
- 标题：思源宋体（Noto Serif SC）或有衬线感的字体
- 正文：无衬线字体
- 移动端友好

【页面结构】

1. 首页 /
- 首屏：大标题"内在结构养育"，副标题"一套以'心神'为核心的专业育儿方法论"，金句"你对待孩子的方式，就是孩子内心世界的建筑图纸"，两个按钮（写下我的育儿初心、了解内在结构）
- 首屏右侧或下方：心灵宫殿示意图（中心是"心神"，三大系统环绕：供能，保护、定向）
- 三入口卡片：育儿初心 / 内在结构 / 落地工具
- 理念区：一句话定义 + 三个独特基因卡片
- 初心预览：成全孩子五层次 + 彼此滋养三层次
- 理论预览：六大结构图 + 十大能力时间轴
- 彼此滋养区：三列卡片（彼此看见/理解/支持）
- 工具区：望杏成林 + 荔枝测评
- 故事区：朋大大简介
- Footer：导航 + 版权

2. 理论页 /theory
- 六大内在结构详解（可展开卡片）
- 十大心神能力时间轴（横向桌面/纵向移动端）
- 结构与能力关系说明

3. 工具页 /tools
- 两个工具卡片：望杏成林、荔枝测评
- 预留未来工具位置

4. 关于我们页 /about
- 创始人故事
- 理论渊源关键词
- 联系方式

5. 初心共鸣页 /intent
- 成全孩子五层次完整展示
- 彼此滋养三层次完整展示
- 五步共鸣交互：输入初心 → 展示理念 → 评分 → 表达感受 → 生成报告
- 海报生成（竖版，可分享）

【技术要求】
- Next.js 16 + React 19 + TypeScript
- Tailwind CSS
- 移动优先，响应式
- 生成 Canvas 海报：400x600px，暖橙+米白配色

【特殊需求】
- 海报是核心分享物料，需要精美、适合微信传播
- 不需要焦虑营销内容
- 大量留白，克制设计
```

---

## 使用方法

1. 打开 https://v0.dev
2. 点击 Sign in，用 GitHub 账号登录（免费）
3. 在输入框粘贴上方 Prompt 内容
4. 等待 AI 生成设计方案
5. 如果需要调整，可以继续对话：
   - "调整色彩更暖一些"
   - "首页首屏再加一个插画"
   - "理论页的时间轴改成纵向"
